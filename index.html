📐 Regras de Gramática

Gramática

Pronomes Pessoais

Toque para ver

Je, Tu, Il/Elle, Nous, Vous, Ils/Elles

Eu, Tu, Ele/Ela, Nós, Vós/Você(s), Eles/Elas

Gramática

Verbo ÊTRE (Ser/Estar)

Toque para ver

Je suis / Tu es / Il est

Nôus sommes / Vous êtes / Ils sont

Gramática

Negação Simples

Toque para ver

Ne + Verbo + Pas

Exemplo: Je ne sais pas (Eu não sei)

🗣️ Expressões & Palavras Úteis

Expressão

"Bonjour !"

Toque para ver

Bom dia / Olá

Usado durante o dia de forma formal ou informal.

Expressão

"S'il vous plaît"

Toque para ver

Por favor

Forma educada/formal (Usado com pessoas que não conhece).

Vocabulário

"Merci beaucoup !"

Toque para ver

Muito obrigado(a)!

Usado para agradecer com intensidade.

Expressão

"Ça va ?"

Toque para ver

Tudo bem? / Como vai?

Muito comum no dia a dia entre amigos.
